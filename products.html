SectionPro

Section properties calculator for marine structural profiles.

Overview

SectionPro computes structural properties (area, moments of inertia, section moduli, radii of gyration, neutral axis) for marine structural profiles. Supports L-profile, T-profile, Flat Bar, and Holland Profile (HP) per EN 10067. Part of the Rule-Based Design suite.

Features

L, T, FB, HP profile support
EN 10067 compliance
Attached plate calculations
BV NR467 corrosion allowance
Interactive 2D sketch
Instant results, no signup
Browser-based
Free for individual use

Technology

EN 10067 BV NR467 Multi-class

BeamCore

Beam structural analysis using Direct Stiffness Method.

Overview

BeamCore is a browser-based beam structural analysis tool using the Direct Stiffness Method. Solve simply supported beams, cantilevers, continuous beams, and multi-span structures with point loads, distributed loads, and applied moments. Built for naval architects, marine engineers, and structural designers.

Features

Direct Stiffness Method (Euler-Bernoulli)
Pinned, fixed, roller supports
Point, UDL, and moment loads
Multi-span continuous beams
FB, L, T, HP profile library
A, AH32, AH36 steel grades
Shear, moment, deflection diagrams
Stress and utilization checks
PDF report export
Server-side computation

Technology

Direct Stiffness Euler-Bernoulli EN 10067 Python · NumPy

NODAL

Beam-based grillage solver for ship structures.

Overview

NODAL is a beam-based grillage solver for marine structures — hatch covers, deck panels, bulkheads, double bottoms, crane pedestals, and stiffened panels. Built specifically for marine engineers, with HP and FB profile libraries, AH36/DH36 steel grades, and class society compliance built in.

Features

Timoshenko beam stiffness
6 DOF per node, 3D analysis
Marine HP and FB profiles
AH36, DH36 steel grades
Multiple load case support
DXF layer-based input
Real-time 3D visualization
DNV class compliance

Technology

Beam Theory Timoshenko DNV CSR Three.js
